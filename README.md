# ⚔️ WarriorNodes

WarriorNodes is a Minecraft server hosting platform project.

## 🚀 Features

- Minecraft server dashboard
- Server creation
- Start / Stop / Restart controls
- Server console
- File manager
- Plugin management
- Server RAM and storage management
- User accounts
- Coins system
- Admin panel
- User and server management
- Minecraft-themed dark UI

## 🎮 Planned Server Software

- Paper
- Purpur
- Spigot

## 🛠️ Technology

- Node.js
- Express
- PostgreSQL
- Redis
- Docker

## 📱 Development

WarriorNodes is being developed with a mobile-friendly dashboard and can be managed from a phone.

## ⚠️ Project Status

This project is currently under development.

The first version is a working dashboard prototype. Real Minecraft server creation, authentication, database, nodes and production hosting will be added in later versions.
